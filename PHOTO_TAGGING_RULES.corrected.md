AMBRIA — PHOTO TAGGING RULES  (corrected to match current inventory / codebase, 2026-07-23)

‼️ MOST IMPORTANT — PRECISION OVER RECALL (do not hallucinate)
Tag ONLY what is clearly and actually visible in THIS photo. It is far better to MISS an item than to
INVENT one. Before you add ANY element, check that you can point to it in the image — if you cannot,
do not add it. NEVER add an item just because it is typical for this kind of setup: e.g. do not add
sofas, side chairs, coffee tables, consoles, pedestals, pots, or seating to a photo that only shows an
entrance arch, a backdrop, or an empty stage. If you are not sure an item is present, LEAVE IT OUT. A
short, fully-correct element list is much better than a long list padded with items that aren't there.

LIGHTING
1. If the photo shows any external/added lights, count and tag LED Light — count every visible light fixture.
2. If crystals are hanging as part of a chandelier, do NOT tag crystal separately (it is included in the Chandelier).
3. If you see a ring of crystals with long hanging strings (separate from the chandelier body), tag Crystal (sub-category "Hanging Pattern").

LOUNGES
4. A Lounge always contains Sofas — tag Sofa (see Seating rules below for sizing).
5. Centre Lounge = a lounge with sofas and open access on all 4 sides.
6. Side Lounge = a lounge covered on one side (usually the back).
7. Open Sofa Lounge = a lounge with only sofa and no covering, no backdrop, no structure.

SEATING
8. Sofas are not split into "2 Seater"/"3 Seater" sub-categories — match by NAME instead: search inventory for the sofa name whose size matches what's shown in the photo (e.g. a name containing "2 Seater" or "3 Seater").
9. Add 1 x Coffee Table for every 3 sofas.
10. If sofa seating is L-shaped (2 sofas), add 1 coffee table.

FLORALS & PROPS
11. If you add a Pedestal, also add its top: if a pot is clearly visible tag Flower Pot Large (or Medium/Small to match the pot size); if only flowers are visible (no pot) tag the matching floral pattern/recipe by name. NEVER tag "Flower Bunch" — every bunch item is an Artificial Flower (rule 16) and is never tagged.
12. Any self-standing fibre prop → tag it under a REAL sub-category, not "Fibre Pot" (which does not exist): a self-standing pot → Self Standing Big Pot; a figurative fibre prop (swan / lion / peacock / fountain / elephant etc.) → Installations Floral; a smaller fibre pot → Flower Pot Small / Medium / Large by size.
13. Any metal or fibre element containing water and petals → tag Urli.
14. Floating Floral = a floral pattern in floating style attached to a structure (a recipe-driven floral, flowers only — no physical inventory). It is never a hanging pattern.
15. If flowers are wrapped around or arranged along ANY structure — a truss pillar, an arch, a backdrop frame, a mandap, a vedi, or drapes — tag Flower Reet (a recipe-driven floral pattern; use Flower Garden or Greens Reet if that matches better). This is the default tag for dense structural florals. Do NOT tag "Phool Ki Chaadar" for these — "Phool Ki Chaadar" is ONLY the flat flower sheet/curtain (e.g. held over a couple or hung as a sheet), never general flower arrangements on a structure.
16. NEVER tag artificial flowers or foliage — including any item whose sub-category is "Artificial Flower" (e.g. "Green bunch", "Mixed Artificial Flower Bunch", any "…foliage"). This sub-category is hidden and is stripped in code. No exceptions.

CENTERPIECE (full table set)
17. If you see a centerpiece, add: Flower Pot (choose Small/Medium/Large based on the pot size shown) + 1 Round Table.
18. If you see a Coffee Table, tag Coffee Table only — its floral/candle contents are already included as part of the Coffee Table kit. Do not add a separate Flower Pot for it.

ENTRANCE
19. When you tag an Entrance photo, also add a BTR stand (sub-category "BTR" — e.g. BTR Stand, Jaimala Stand, Easel Stand). Do NOT tag a sunboard — a sunboard is a Print material (added through the Print flow, like Flex/Vinyl), not a taggable element.
20. If you see a glass mirror stand at the entrance, tag Mirror BTR (sub-category "BTR").

STRUCTURES — pick by DEPTH (3D if it has depth, 2D if flat) + MATERIAL + shape.
Use these EXACT sub-category names (they must match for routing to work):
21. Wooden, flat panel .......................... Wooden 2 D Pannel
22. Wooden, flat arch ........................... Wooden 2D Arch
23. Wooden, 3D arch ............................. Wooden 3D Arch
24. Wooden, 3D panel ............................ Wooden 3D Pannel
25. Wrought iron, flat (2D) — arch OR panel ..... Wrought iron 2D
26. Wrought iron, 3D — arch OR panel ............ Wrought Iron 3D
27. Glass, flat panel ........................... Glass Panel 2D
28. Glass, 3D panel ............................. Glass Panel 3D
28.a. If there is no cloth on the structure, don't add it to the truss section — do a lookup in the IMS inventory and add it in the element breakdown.

WALKWAY / AISLE
29. A Walkway/Aisle is captured as part of the Platform section (same 3D/2D structure fields as other platforms) — do NOT tag "Aisle" or "Walkway" as its own separate element.

BAR COUNTER / MANDAP-VEDI
30. If you see a Bar Counter, tag it under the BAR sub-category (e.g. "new bar", "moulding bar", "Star BAR").
31. If you see a Mandap or Vedi structure, tag it using the closest matching sub-category (vedi, or a STRUCTURES material/depth/shape name above).

CONSOLE TABLE
32. Console Table = tag the Console Table itself only. NEVER separately tag any item placed on top of a console — candles, lamps, baskets, flowers, or any other decor — even if that specific item isn't listed in the console's own kit recipe. Always prefer the console's kit as the single covering item; nothing else gets added for it.
33. If flowers/pots/accessories are arranged just BEHIND a sofa (the console table itself may be hidden by the sofa back), add 1 x Console Table for each such set — e.g. 4 sets = 4 Console Tables.

SPECIAL STRUCTURES
34. If you see a man-made tree-shaped structure with 4 arms, add 1 x Tree, plus its floral fill tagged as the matching floral pattern (qty as visible) — never as "Flower Bunch" (that sub-category is artificial-only and is never tagged).
35. If you see a backdrop with an elevated platform and 1 couch, always tag it as a Stage.

DO NOT DOUBLE-COUNT
36. NEVER add Carpet, Fabric, Truss, or Platform as separate sub-categories — they are already captured in the 3-dim / 2-dim structure fields. Adding them again duplicates and doubles the cost.
   But you SHOULD capture real structural decor like Jali, Arch, wooden arches, etc. — those are added in the element breakdown.
37. "Default carpet = Old Carpet cost" is a config default used elsewhere in the build, not a taggable element — never tag "Old Carpet" or any carpet as its own element; rule 36 always applies.

GENERAL
38. Always read each sub-category's unit and fill the quantity in that unit.
39. Default size = Medium (M) unless the photo clearly shows an oversized/large item (→ Big) or a miniature/small item (→ Small).

COMMON MISTAKES — AVOID THESE (they are the most frequent tagging errors)
40. ALWAYS tag visible SEATING — sofa, couch, chair, bench — even when it is partly hidden by drapes, tables, flowers, or people. Missing an obvious sofa/couch is a top error.
41. TAG ONLY WHAT IS VISIBLE. Never add an item just because it is typical for this kind of setup. If you cannot clearly see it in THIS photo, do not tag it.
42. Do NOT tag a Mattress, pouffe, takhat, or floor cushion unless it is clearly and unambiguously visible as that item. Pooled/bunched fabric, drapes, carpet, or shadows are NOT mattresses — do not invent them.
43. Dense florals wrapped or arranged along a structure, drape, arch, or pillar are Flower Reet (see Rule 15) — never a generic "flower bedding"/"floral wall" installation, and never Phool Ki Chaadar.
44. Scene type: a seating area with sofas/couches under a floral canopy or drapes is a Lounge or Entrance, NOT a Stage. Only tag Stage when there is a clear elevated platform + backdrop + couch (Rule 36).
45. Do not output absurd quantities. If you are counting individual flowers/roses, that is wrong — florals are tagged as a Flower Reet/pattern in its own unit (rft/pc), not as hundreds of individual pieces.
